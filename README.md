# Smart Waste Management System

An IoT-based smart waste segregation system using NIR spectroscopy and Arduino.

## 🔹 Features
- Real-time waste detection
- Automated segregation using servo mechanism
- IoT-based fill level monitoring
- Smart dashboard tracking
- End-to-end waste traceability

## 🔹 System Flow
Waste Input  
→ NIR Detection  
→ Arduino Processing  
→ Servo Segregation  
→ IoT Monitoring  
→ Dashboard Analytics  

## 🔹 Tech Stack
- Arduino
- NIR Spectroscopy
- Ultrasonic Sensors
- IoT (Cloud Integration)
- Web Dashboard

## 🔹 Project Structure
hardware/ → Arduino code  
software/ → Detection logic  
dataset/ → Sample training data  
app/ → Monitoring dashboard  
docs/ → Architecture diagrams
